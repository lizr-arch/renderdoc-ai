# RenderDoc AI 增强版：产品总方针（草案）

## 目标
打造面向渲染/游戏/TA 的“AI 原生”调试与分析体验：  
1) 一键可用的权威报告；2) 无 GUI/批量/CI 的离线能力；3) 按需实时数据接口；4) AI 驱动的高阶解读与脚本化。

## 四大功能边界
- **GUI 报告（主路径）**：用户在 RenderDoc 内点按钮生成官方 HTML 报告，完整、可信、可视化。
- **离线/CI 报告（次路径）**：renderdoccmd + CLI，复用同一模板，适合无 GUI、批处理、回归对比、容灾。
- **MCP 实时接口**：按需访问已加载捕获的实时数据（管线、计时、资源、反查），面向脚本/自动化/AI，不负责整份报告。
- **AI Skill（智能层）**：两类能力——
  - 安装/自检：一键安装扩展、检测环境、健康检查。
  - 增值分析：读取报告/快照/MCP 数据，做高阶解读（瓶颈归因、管线审阅、Shader 公式提取、对比回归、行动清单），生成脚本/结论。

## 设计原则
1) 单一职责，少重叠：报告生成走 GUI/离线；MCP 只供实时查询；Skill 只做“编排+解读”。  
2) 模板统一：GUI/离线报告共享 HTML/JS/CSS 模板，数据适配器区分来源（ReplayController vs XML/JSON）。  
3) 轻重分层：默认输出轻量摘要，可按需展开细节；离线模式在字段缺失时标注占位与补救路径（MCP）。  
4) 可溯源：结论必须可跳转到 event_id / resource / marker；计时与资源引用需给出证据链。  
5) 自动化友好：所有步骤可脚本化（CLI/MCP），CI 能跑；Skill 可把自然语言意图翻译成操作序列。

## 路径示意
- GUI：捕获 → 一键导出（统一模板） → 报告 + JSON 快照。  
- 离线：renderdoccmd export (XML/JSON/zip.xml) → CLI 生成报告（统一模板） → 报告 + JSON 快照。  
- MCP：RenderDoc + 扩展 → `renderdoc-mcp` 服务 → API 查询局部数据。  
- Skill：读取报告/快照/MCP 响应 → 生成结论/脚本/行动清单。

## 近期优先级
1) 模板统一与数据适配层抽象（GUI + CLI 共用）。  
2) CLI 增强：轻量/全量模式、缺失提示、JSON 快照输出。  
3) MCP 样例脚本：计时热点、管线/资源反查、局部 JSON 导出。  
4) Skill 设计落地：安装自检 + 高阶分析动作（5 个高频用例）。

## 度量
- 报告一致性：GUI/离线输出差异 <5% 字段缺口（可标注）；模板单一。  
- 使用门槛：新用户 3 步内完成 MCP 自检并获取 `get_capture_status`。  
- AI 价值：生成的结论/脚本被人工采纳率、Top-N 瓶颈命中率、故障定位时间。
