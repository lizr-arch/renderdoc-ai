# RDC Analyzer 项目愿景与开发路线图

> **版本**: 1.0.0  
> **创建日期**: 2025-02-05  
> **状态**: ✅ 已确认

---

## 🎯 项目愿景

**一句话描述**: 让任何人都能轻松分析任何设备的 GPU 帧捕获，借助 AI 获得专业级优化建议。

---

## 📋 四大核心目标

### 目标 1: 跨平台 RDC 回放 ✅

> **痛点**: 原版 RenderDoc 无法在不同 GPU 间回放 RDC 文件

**解决方案**: Vulkan 内存类型智能重映射

| 场景 | 状态 |
|------|------|
| PC 跨代 GPU（RTX 2060 → RTX 4070 Ti） | ✅ 已实现 |
| 移动端 → PC（Mali/Adreno → PC） | ✅ 已实现 |
| 跨厂商（NVIDIA ↔ AMD） | ⚠️ 部分支持 |

**技术文档**: `docs/analysis/CROSS_GPU_REPLAY_GUIDE.md`

---

### 目标 2: 自动化性能分析报告 🔧

> **痛点**: 分析 RDC 需要专业知识，新手难以发现问题

**解决方案**: 规则引擎 + 可视化报告

| 能力 | 状态 | 说明 |
|------|------|------|
| Draw Call 分析 | ✅ | 数量、批次、排序 |
| 纹理分析 | ✅ | 尺寸、格式、内存 |
| **纹理缩略图** | 🔧 需完善 | 需要 Python API |
| **Shader 源码** | 🔧 需完善 | 需要 Python API |
| **RT 快照** | 🔧 需完善 | 需要 Python API |
| 性能规则检测 | ✅ | 77+ 规则 |
| HTML 报告输出 | ✅ | Bundle 格式 |
| EXE 内置面板 | ⏳ 规划中 | Phase 2 |

---

### 目标 3: 大模型 AI 集成 🆕

> **痛点**: Shader 分析需要深厚功底，跨平台移植耗时

**解决方案**: MCP 集成，AI 辅助分析

| 能力 | 优先级 | 说明 |
|------|--------|------|
| **Shader 翻译** (SPIR-V/GLSL → HLSL) | ⭐ P0 | 用户首选功能 |
| Shader 性能分析 | P1 | 识别瓶颈指令 |
| 报告智能问答 | P1 | 自然语言查询 |
| 优化建议生成 | P2 | AI 推荐修复方案 |

**MCP 架构**:
```
┌─────────────────────────────────────────────────────────────┐
│                    RDC Analyzer MCP                          │
├─────────────────────────────────────────────────────────────┤
│  analyze_rdc        - 分析 RDC 文件，返回结构化结果         │
│  translate_shader   - SPIR-V/GLSL → HLSL 翻译 ⭐            │
│  analyze_shader     - 分析 Shader 性能瓶颈                  │
│  compare_reports    - 对比两份分析报告                       │
│  ask_report         - 报告智能问答                           │
└─────────────────────────────────────────────────────────────┘
```

---

### 目标 4: 报告对比分析 🔧

> **痛点**: 优化效果难以量化，A/B 测试缺乏可视化

**解决方案**: 结构化对比 + 差异可视化

| 能力 | 状态 | 说明 |
|------|------|------|
| 基础对比 | ✅ | compare_rdc.py |
| Draw Call 差异 | ✅ | 数量变化 |
| 纹理差异 | ✅ | 内存变化 |
| **可视化对比** | ⏳ 规划中 | 并排 + 高亮 |
| **AI 总结** | ⏳ 规划中 | "优化了什么？" |

---

## 🔍 核心点 vs 次要点

### 核心点 (Must Have)

| # | 能力 | 原因 |
|---|------|------|
| 1 | **跨 GPU 回放** | 一切分析的前提 |
| 2 | **完整资源提取** | 报告有内容才有价值 |
| 3 | **结构化 JSON 输出** | 支持 MCP/对比/多 UI |
| 4 | **Shader 翻译 MCP** | AI 核心能力 |

### 次要点 (Nice to Have)

| 能力 | 原因 |
|------|------|
| HTML 美观度 | 功能优先，美化后置 |
| 多语言支持 | 先做好中文版 |
| 性能计数器 | 依赖 GPU SDK，复杂 |
| 实时分析 | 聚焦离线分析 |

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **核心引擎** | Python 3.10+ | 分析逻辑 |

| **EXE 集成** | Qt 6 (C++) | 内置面板 |
| **大模型** | OpenAI/Claude API | Shader 翻译 |
