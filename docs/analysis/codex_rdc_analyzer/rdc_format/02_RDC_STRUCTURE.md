## 一、文件总体布局

RDC 文件按顺序排列以下数据块：

```
┌─────────────────────────────────────────────────────────────────────┐
│                           RDC File                                  │
├─────────────────────────────────────────────────────────────────────┤
│  1. FileHeader (32 bytes)                                           │
│     ├── magic: 0x434F4452 ("RDOC" little-endian)                    │
│     ├── version: 0x00000102 (v1.2)                                  │
│     ├── headerLength: 到 Sections 开始的偏移                         │
│     └── progVersion: "v1.35 abc123" (16字节)                        │
├─────────────────────────────────────────────────────────────────────┤
│  2. BinaryThumbnail (8 + N bytes)                                   │
│     ├── width, height: uint16 × 2                                   │
│     ├── length: uint32                                              │
│     └── data[length]: JPG 压缩图像                                   │
├─────────────────────────────────────────────────────────────────────┤
│  3. CaptureMetaData (variable)                                      │
│     ├── machineIdent: uint64 (机器标识)                              │
│     ├── driverID: uint32 (1=D3D11, 4=D3D12, 6=Vulkan...)            │
│     ├── driverNameLength: uint8                                     │
│     └── driverName[]: ASCII 字符串                                   │
├─────────────────────────────────────────────────────────────────────┤
│  4. CaptureTimeBase (16 bytes) [v1.2+]                              │
│     ├── timeBase: uint64 (基准时间戳)                                │
│     └── timeFreq: double (ticks → 微秒)                              │
├─────────────────────────────────────────────────────────────────────┤
│  5. Sections[] (紧密排列)                                            │
│     ├── Section 0: FrameCapture (必须是第一个)                       │
│     ├── Section 1: ResolveDatabase                                  │
│     ├── Section 2: ExtendedThumbnail                                │
│     ├── Section 3: Bookmarks / Notes / ...                          │
│     └── ...                                                         │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、各数据块详解

### 1️⃣ FileHeader（文件头）— "这是什么文件"

```
字节位置: 0 ~ 31 (前 32 个字节)

┌──────────────────────────────────────────────────────────────┐
│  字节 0-3:   "RDOC" (4个字母，表示这是 RDC 文件)              │
│  字节 4-7:   0x00000102 (版本号，当前是 1.2)                  │
│  字节 8-11:  0x000000A0 (数据开始位置的偏移量)                │
│  字节 12-15: 0x00000000 (保留)                                │
│  字节 16-31: "v1.35 abc123" (RenderDoc 版本字符串)            │
└──────────────────────────────────────────────────────────────┘
```

**人话翻译**：
- "RDOC" = 文件身份证，证明这是 RenderDoc 的文件
- 版本号 = 告诉程序该用什么规则解析
- RenderDoc 版本 = 用哪个版本的 RenderDoc 捕获的

---

### 2️⃣ Thumbnail（缩略图）— "预览图"

```
紧跟在 FileHeader 后面

┌──────────────────────────────────────────────────────────────┐
│  字节 0-1:   宽度 (如 320)                                    │
│  字节 2-3:   高度 (如 240)                                    │
│  字节 4-7:   图片数据长度 (如 15000 字节)                     │
│  字节 8-N:   JPG 图片的原始数据                               │
└──────────────────────────────────────────────────────────────┘
```

**人话翻译**：
- 这就是你在 RenderDoc 里看到的那个小预览图
- 格式是 JPG，可以直接提取出来用图片查看器打开

---

### 3️⃣ Metadata（元数据）— "捕获环境信息"

```
┌──────────────────────────────────────────────────────────────┐
│  machineIdent:    0x0102030405060708 (机器唯一标识)          │
│  driverID:        6 (图形 API: 6=Vulkan, 4=D3D12, 1=D3D11)   │
│  driverNameLen:   6                                          │
│  driverName:      "Vulkan"                                   │
└──────────────────────────────────────────────────────────────┘
```

**Driver ID 对照表**：

| ID | 图形 API |
|----|----------|
| 1 | D3D11 |
| 4 | D3D12 |
| 6 | Vulkan |
| 7 | OpenGL |
| 8 | OpenGL ES |

---

### 4️⃣ Sections（章节）— "数据的大分类"

RDC 文件把数据分成多个"章节"（Section），每个章节存不同类型的内容：

```
┌─────────────────────────────────────────────────────────────────┐
│  Section 0: FrameCapture       ← 【最重要】所有 GPU 命令都在这里  │
│  Section 1: ResolveDatabase    ← 调试符号（函数名对应关系）       │
│  Section 2: ExtendedThumbnail  ← 高清版缩略图                    │
│  Section 3: Notes              ← 用户笔记                        │
│  ...                                                            │
└─────────────────────────────────────────────────────────────────┘
```

**每个 Section 的结构**（就像每一章的格式）：

```
┌────────────────────────────────────────────────────────┐
│  Section Header (章节头)                               │
│  ├── 类型: 1 (表示 FrameCapture)                       │
│  ├── 压缩后大小: 5,000,000 字节                        │
│  ├── 原始大小: 50,000,000 字节                         │
│  ├── 压缩方式: LZ4                                     │
│  └── 名称: "FrameCapture"                              │
├────────────────────────────────────────────────────────┤
│  Section Data (章节内容)                               │
│  └── [压缩后的二进制数据...]                           │
└────────────────────────────────────────────────────────┘
```

**SectionType 枚举**：

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Unknown | 未知/自定义 |
| 1 | **FrameCapture** | 核心帧数据（API 调用 + 资源） |
| 2 | ResolveDatabase | 符号解析数据库 |
| 3 | Bookmarks | UI 书签 |
| 4 | Notes | 用户笔记 |
| 5 | ResourceRenames | 资源重命名 |
| 6 | AMDRGPProfile | AMD RGP 配置 |
| 7 | ExtendedThumbnail | 高质量缩略图 |
| 8 | EmbeddedLogfile | 嵌入日志 |
| 9 | EditedShaders | 编辑过的 Shader |

---

### 5️⃣ Chunks（具体命令）— "每一句话"

在 FrameCapture Section 里面，数据被进一步分成一条条"Chunk"：

```
┌─────────────────────────────────────────────────────────────────┐
│  FrameCapture 解压后的内容：                                     │
│                                                                 │
│  Chunk 0: [初始化 GPU 驱动]                                      │
│  Chunk 1: [列出所有要恢复的资源]                                  │
│  Chunk 2: [恢复纹理 A 的数据]                                     │
│  Chunk 3: [恢复纹理 B 的数据]                                     │
│  ...                                                            │
│  Chunk 100: [开始捕获]                                           │
│  Chunk 101: vkCmdBeginRenderPass  ← "开始画画"                   │
│  Chunk 102: vkCmdBindPipeline     ← "选择画笔"                   │
│  Chunk 103: vkCmdBindDescriptorSets ← "选择颜料(纹理)"           │
│  Chunk 104: vkCmdDraw             ← "画 1000 个三角形"           │
│  Chunk 105: vkCmdDraw             ← "再画 500 个三角形"          │
│  ...                                                            │
│  Chunk 999: [结束捕获]                                           │
└─────────────────────────────────────────────────────────────────┘
```

**每个 Chunk 的结构**：

```
┌────────────────────────────────────────┐
│  Chunk Header (4 字节)                 │
│  ├── 低 16 位: Chunk ID (命令类型)     │
│  └── 高 16 位: 标志位                  │
├────────────────────────────────────────┤
│  Length (4 或 8 字节)                  │
│  └── 这个 Chunk 的数据长度             │
├────────────────────────────────────────┤
│  Data (变长)                           │
│  └── 命令的参数                        │
└────────────────────────────────────────┘
```

## 三、用真实字节来看结构

### 打开一个真实的 RDC 文件（用十六进制查看器）

```
地址        00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F    解码
─────────────────────────────────────────────────────────────────────
00000000    52 44 4F 43 02 01 00 00 A0 00 00 00 00 00 00 00    RDOC............
00000010    76 31 2E 33 35 00 00 00 00 00 00 00 00 00 00 00    v1.35...........
            ↑_________↑ ↑_______↑ ↑_______↑                   ↑______________↑
              Magic     Version   Offset                       程序版本字符串
              "RDOC"     0x102     160
```

**解读这 32 个字节**：

| 字节范围 | 十六进制 | 含义 |
|----------|----------|------|
| 0-3 | `52 44 4F 43` | ASCII "RDOC"，文件标识 |
| 4-7 | `02 01 00 00` | 小端序，读作 0x00000102 = v1.2 |
| 8-11 | `A0 00 00 00` | 小端序，0x000000A0 = 160，数据从第 160 字节开始 |
| 16-31 | `76 31 2E 33 35...` | "v1.35"，RenderDoc 版本 |

## 四、完整的字节布局图

```
┌────────────────────────────────────────────────────────────────────────┐
│ 偏移量           内容                          大小                    │
├────────────────────────────────────────────────────────────────────────┤
│ 0x0000          FileHeader                     32 字节                 │
│                 ├── magic (RDOC)               4 字节                  │
│                 ├── version                    4 字节                  │
│                 ├── headerLength               4 字节                  │
│                 ├── reserved                   4 字节                  │
│                 └── progVersion                16 字节                 │
├────────────────────────────────────────────────────────────────────────┤
│ 0x0020          Thumbnail                      8 + N 字节              │
│                 ├── width                      2 字节                  │
│                 ├── height                     2 字节                  │
│                 ├── length                     4 字节                  │
│                 └── jpgData[length]            N 字节                  │
├────────────────────────────────────────────────────────────────────────┤
│ 0x0020+N        Metadata                       变长                    │
│                 ├── machineIdent               8 字节                  │
│                 ├── driverID                   4 字节                  │
│                 ├── driverNameLen              1 字节                  │
│                 └── driverName[]               变长                    │
├────────────────────────────────────────────────────────────────────────┤
│ 0x00A0          Section[0] Header              40+ 字节                │
│ (headerLength)  ├── isASCII                    1 字节                  │
│                 ├── zero[3]                    3 字节                  │
│                 ├── sectionType                4 字节                  │
│                 ├── compressedLength           8 字节                  │
│                 ├── uncompressedLength         8 字节                  │
│                 ├── sectionVersion             8 字节                  │
│                 ├── sectionFlags               4 字节                  │
│                 ├── nameLen                    4 字节                  │
│                 └── name[nameLen]              变长                    │
├────────────────────────────────────────────────────────────────────────┤
│ ...             Section[0] Data                compressedLength 字节   │
│                 └── [压缩的 Chunks 数据]                               │
├────────────────────────────────────────────────────────────────────────┤
│ ...             Section[1] Header + Data                               │
│ ...             Section[2] Header + Data                               │
│ ...             ...                                                    │
└────────────────────────────────────────────────────────────────────────┘
```
