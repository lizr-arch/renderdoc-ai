## 1. 整体架构概览

RenderDoc 是一个图形调试器，核心功能分为两个阶段：

1. **捕获阶段 (Capture)**: Hook 图形 API，记录所有调用和资源到 `.rdc` 文件
2. **回放阶段 (Replay)**: 读取 `.rdc` 文件，重建 GPU 状态，提供调试功能

```

│                           RenderDoc 架构                                 │
```

## 2. 核心模块详解

### 2.1 序列化层 (Serialisation)

**职责**: RDC 文件的读写、压缩/解压、流式 I/O

```
┌─────────────────────────────────────────────────────────────────┐
│                      序列化层                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐       │
│  │   RDCFile   │────▶│ StreamReader│────▶│ LZ4/ZSTD    │       │
│  │   (.rdc)    │     │   /Writer   │     │ Compressor  │       │
│  └─────────────┘     └─────────────┘     └─────────────┘       │
│         │                   │                                   │
│         │                   ▼                                   │
│         │            ┌─────────────┐                           │
│         │            │  Serialiser │ ← 模板类，处理 Chunk       │
│         │            │   <Read>    │                           │
│         │            │   <Write>   │                           │
│         │            └─────────────┘                           │
│         │                                                      │
│         ▼                                                      │
│  ┌─────────────────────────────────────────────────────────┐  │
│  │                    Section 布局                          │  │
│  ├─────────────────────────────────────────────────────────┤  │
│  │  Header │ FrameCapture │ ResolveDB │ Thumbnail │ ...   │  │
│  └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**关键类**:

| 类 | 文件 | 职责 |
|----|------|------|
| `RDCFile` | `serialise/rdcfile.h` | RDC 文件容器，管理 Section |
| `StreamReader/Writer` | `serialise/streamio.h` | 二进制流 I/O |
| `Serialiser<>` | `serialise/serialiser.h` | 序列化模板，处理类型转换 |
| `LZ4Compressor` | `serialise/lz4io.h` | LZ4 压缩 |
| `ZSTDCompressor` | `serialise/zstdio.h` | ZSTD 压缩 |

**关键模式**:

- `{api}_replay.cpp` - 回放入口，实现 `IReplayDriver`

- `{api}_manager.cpp` - 资源管理
- `{api}_serialise.cpp` - Chunk 序列化/反序列化
- `{api}_resources.cpp` - 资源定义

## 3. 数据流

### 3.1 捕获流程 (Capture Flow)

```
应用程序 API 调用
        │
        ▼
┌───────────────────┐
│   API Hooks       │ ← 拦截 D3D11/D3D12/Vulkan/GL 调用
│   (*_hooks.cpp)   │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│  Wrapped Device   │ ← 包装设备，记录所有状态
│  (*_device.cpp)   │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│   Serialiser      │ ← 序列化 API 调用为 Chunk
│   (serialiser.h)  │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│   RDCFile         │ ← 写入 RDC 文件
│   (rdcfile.cpp)   │
└───────────────────┘
         │
         ▼
    capture.rdc
```

### 3.2 回放流程 (Replay Flow)

```
    capture.rdc
         │
         ▼
┌───────────────────┐
│   CaptureFile     │ ← Python/UI 入口点
│   OpenFile()      │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│   RDCFile         │ ← 解析文件头和 Section 索引
│   Open()          │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│ ReplayController  │ ← 创建回放设备
│ CreateDevice()    │
└────────┬──────────┘
         │ 根据 RDCDriver 选择驱动
         ▼
┌───────────────────┐
│ {API}Replay       │ ← 读取初始化数据
│ ReadLogInit()     │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│   Serialiser      │ ← 反序列化 Chunk
│   (Read mode)     │
└────────┬──────────┘
         │
         ▼
┌───────────────────┐
│   API State       │ ← 重建 GPU 状态
│   Reconstruction  │
└───────────────────┘
         │
         ▼
   可用于调试的回放环境
```

## 5. 关键设计模式

### 5.1 Chunk 序列化模式

每个 API 调用被序列化为一个 **Chunk**：

```cpp
// 写入 (捕获时)
{
  SCOPED_SERIALISE_CHUNK(D3D11Chunk::Draw);
  SERIALISE_ELEMENT(VertexCount);
  SERIALISE_ELEMENT(StartVertexLocation);
}

// 读取 (回放时)
switch(chunk)
{
  case D3D11Chunk::Draw:
  {
    uint32_t VertexCount, StartVertexLocation;
    SERIALISE_ELEMENT(VertexCount);
    SERIALISE_ELEMENT(StartVertexLocation);
    m_pDevice->Draw(VertexCount, StartVertexLocation);
    break;
  }
}
```

### 5.2 资源 ID 映射

```
捕获时:
  真实指针 → ResourceId (序列化)
  
回放时:
  ResourceId → 新创建的资源指针 (反序列化)
  
┌──────────────┐     ┌──────────────┐
│ Real Pointer │────▶│  ResourceId  │◀────┐
│ (Capture)    │     │  (uint64_t)  │     │
└──────────────┘     └──────────────┘     │
                            │             │
                            ▼             │
                     ┌──────────────┐     │
                     │ New Pointer  │─────┘
                     │ (Replay)     │
                     └──────────────┘
```

### 5.3 初始状态记录

捕获开始时记录所有已存在资源的状态：

```
┌─────────────────────────────────────────────────────────┐
│                   FrameCapture Section                  │
├─────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────┐  │
│  │           Initial State Chunks                    │  │
│  │  (所有已存在资源的完整状态)                         │  │
│  └───────────────────────────────────────────────────┘  │
│                          │                              │
│                          ▼                              │
│  ┌───────────────────────────────────────────────────┐  │
│  │           Frame Chunks                            │  │
│  │  (帧内的所有 API 调用)                              │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```
