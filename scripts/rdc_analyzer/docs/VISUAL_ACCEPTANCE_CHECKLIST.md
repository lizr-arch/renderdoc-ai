## 1) 一页式评分表（总分 100）

- 通过阈值：`>= 85`
- 否决条件：出现任意 `P0`（功能中断）即不通过

| 维度 | 分值 | 验收点（通过标准） |
|------|------|--------------------|
| 信息架构 | 20 | 页面主次清晰；用户能在 10 秒内知道“我在哪、看什么、下一步做什么” |
| 可读性 | 20 | 标题/正文/芯片/按钮层级明确；对齐、间距、字号一致；无拥挤感 |
| 交互反馈 | 20 | 搜索/筛选/排序后，列表与摘要状态即时同步；当前选中状态稳定 |
| 可访问性 | 20 | 焦点可见；键盘可达；对比度可读；长列表可滚动 |
| 稳定性 | 20 | 无错位/遮挡/抖动；分页切换稳定；空状态与失败状态有明确提示 |

## 2) 页面级检查（按顺序）

### A. `index.html`（90 秒）
- [ ] 四个主入口卡片（Events/Textures/Shaders/Recommendations）可快速识别
- [ ] 核心统计区不溢出、不折叠异常
- [ ] 深浅层信息对比明显（主指标 > 次指标）

### B. `textures.html`（2 分钟）
- [ ] 左栏可滚动（鼠标滚轮/触控板/拖动滚动条都可用）
- [ ] 搜索与排序生效，摘要芯片同步更新（可见数/当前选中/排序方式）
- [ ] 中央主展示区稳定，无挤压/错位
- [ ] 右侧属性栏可滚动（信息多时仍可完整查看）
- [ ] 空缩略图状态文案清晰（不误导为“程序坏了”）

### C. `shaders.html`（1.5 分钟）
- [ ] `查看 HLSL 代码` 与 `AI Shader 优化` 按钮同一视觉层级（不冲突、不遮挡）
- [ ] HLSL 状态徽章（OFF/ON/N/A）切换语义正确
- [ ] 搜索/排序作用于当前可见列表，摘要芯片同步
- [ ] 无 Shader 数据时空状态清晰（含下一步建议）

### D. `events.html`（1.5 分钟）
- [ ] 事件树展开/折叠稳定，无跳闪
- [ ] 搜索定位后可感知（高亮/定位）
- [ ] 与其他页面跳转后，目标项定位/高亮反馈明确

## 3) 缺陷分级（统一口径）

- `P0`：功能中断（按钮不可用、列表不可滚、布局遮挡核心信息、页面崩溃）
- `P1`：高频可用性问题（主操作不明显、状态不一致、搜索排序结果异常）
- `P2`：视觉一致性问题（间距、字重、配色、对齐）
