# E2E 手动测试清单：证据链跳转功能

> **版本**: M3.4  
> **日期**: 2025-01-22  
> **测试范围**: 跨页面跳转和高亮功能验证

---

## 前置条件

1. 已生成包含性能问题的报告包（至少 1 个 warning/critical 级别问题）
2. 报告文件位于可访问的本地路径
3. 使用现代浏览器（Chrome/Firefox/Edge）

---

## 测试用例

### TC-001: 证据链跳转到纹理页面

**步骤**:
1. 打开 `recommendations.html`
2. 选择一个包含 "纹理" 相关问题的建议项（如超大纹理、缺少 Mipmap）
3. 在详情面板找到 "🎯 快速跳转" 区域
4. 点击 "→ 查看纹理" 按钮

**预期结果**:
- [ ] 浏览器跳转到 `textures.html?id=xxx&highlight=true`
- [ ] 目标纹理自动被选中（列表中高亮）
- [ ] 元素有 2 秒的脉冲动画效果（橙色边框闪烁）
- [ ] 页面自动滚动到目标元素可见区域

---

### TC-002: 证据链跳转到事件页面

**步骤**:
1. 打开 `recommendations.html`
2. 选择一个包含事件 ID 的建议项
3. 在 "🎬 相关事件" 区域点击事件标签（如 "EID 1234"）

**预期结果**:
- [ ] 浏览器跳转到 `events.html?eid=xxx&highlight=true`
- [ ] 目标事件自动被选中
- [ ] 元素有脉冲动画高亮效果

---

### TC-003: 证据链跳转到 Shader 页面

**步骤**:
1. 打开 `recommendations.html`
2. 选择一个包含 Shader 相关问题的建议项
3. 在 "📦 受影响资源" 区域点击 Shader 标签

**预期结果**:
- [ ] 浏览器跳转到 `shaders.html?sid=xxx&highlight=true` 或 `?target=xxx`
- [ ] 目标 Shader 自动被选中
- [ ] 元素有脉冲动画高亮效果

---

### TC-004: 证据展示面板内容验证

**步骤**:
1. 打开 `recommendations.html`
2. 选择一个带有完整证据链的问题
3. 检查详情面板的各区域

**预期结果**:
- [ ] "🔗 证据链摘要" 显示一句话总结
- [ ] "📋 证据详情" 显示实际值 vs 阈值
- [ ] "⚡ 影响评分" 显示 0-100 分数（带颜色等级）
- [ ] "✅ 验证方案" 显示验证步骤

---

### TC-005: 直接 URL 深链接验证

**步骤**:
1. 直接在浏览器地址栏输入 `textures.html?id=tex_123&highlight=true`
2. 观察页面加载后的行为

**预期结果**:
- [ ] 如果 tex_123 存在，自动选中并高亮
- [ ] 如果不存在，不会报错（静默失败）

---

### TC-006: navigation.js 控制台日志

**步骤**:
1. 打开任意报告页面
2. 按 F12 打开开发者工具
3. 切换到 Console 标签页
4. 执行跳转操作

**预期结果**:
- [ ] 显示 `[RdcNav] Highlight element: xxx`
- [ ] 无 JavaScript 错误
