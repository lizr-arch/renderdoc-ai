## 📦 Phase 2: RDC 对比分析 (4 任务) ⭐ 核心目标

> **目标**: 实现两个 RDC 文件的差异对比，找出性能回归点
> **预计总工时**: 4 小时

### TASK-010: DiffEngine 核心实现 🟡 待认领
- **优先级**: P0 (高)
- **预计工时**: 90 分钟
- **依赖**: 无
- **涉及文件**: 
  - `diff/diff_engine.py` (新建)
  - `diff/__init__.py` (新建)
  - `tests/test_diff_engine.py` (新建)
- **需求描述**:
  创建对比引擎，输入两个 RDC 解析结果 (JSON dict)，输出结构化差异报告。
- **技术说明**:
  - 输入: 两个 `parse_rdc_xml.py` 的输出 dict (baseline, target)
  - 输出: `DiffReport` 对象，包含各维度差异
- **核心能力**:
  - [ ] Draw Call 数量差异 (新增/删除/顺序变化)
  - [ ] 纹理使用差异 (新增/删除/尺寸变化/格式变化)
  - [ ] Buffer 使用差异 (大小变化)
  - [ ] Shader 变更检测 (新增/删除/修改)
  - [ ] 状态设置差异 (Blend/Depth/Viewport)
  - [ ] 帧统计差异 (total_draws, total_triangles, memory_usage)
- **验收标准**:
  - [ ] `DiffEngine` 类实现 `compare(baseline, target) -> DiffReport` 方法
  - [ ] `DiffReport` 包含 `summary`, `draw_call_diff`, `texture_diff`, `shader_diff`, `state_diff`
  - [ ] 支持 `DiffReport.to_dict()` 和 `DiffReport.to_json()` 序列化
  - [ ] 单元测试: 空数据对比、相同数据对比、差异数据对比
- **验证命令**:
  ```bash
  py -3 -m pytest scripts/rdc_analyzer/tests/test_diff_engine.py -v
  ```
