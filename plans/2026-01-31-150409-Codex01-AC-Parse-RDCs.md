## Approach (Pseudo-code)
```
for each rdc in [战斗特写1, 大远景]:
  ensure rdc exists
  output_dir = D:\backup\rdc_reports\<rdc_name>\
  xml_path = output_dir\<rdc_name>.xml
  html_path = output_dir\<rdc_name>_report.html
  export_dir = output_dir\export\

  # A 路线: rdc -> xml -> html
  renderdoccmd convert -f rdc -o xml -c xml
  py -3 analyze_xml_report.py xml -o html

  # C 路线: 资源导出
  renderdoccmd export rdc -o export_dir --metadata --bindings

  verify xml/html/export_dir
```

## Impact Analysis
- 不修改代码，风险低；主要风险为 `renderdoccmd.exe` 不存在或 export 子命令不可用。

## Risks & Blockers
- `renderdoccmd.exe` 不在预期路径或未包含 `export` 子命令 → 需暂停并请求指示。
- RDC 文件路径含中文/空格 → 必须完整加引号。
- **[BLOCKER]** `renderdoccmd export` 回放失败（硬件不兼容），导致 C 路线无法导出纹理/JSON。
