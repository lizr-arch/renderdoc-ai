# v1.1 格式解码功能开发计划

> **Plan ID**: 2025-01-31-v1.1-format-decoder  
> **目标**: 实现 BC 压缩纹理的 CPU 解码 + PNG 输出  
> **Agent**: Codex Agent A

---

## 1. 目标范围 (Scope)

### 1.1 核心目标

| 目标 | 说明 | 优先级 |
|------|------|--------|
| BC7 解码 | 最常用的高质量压缩格式 | P0 |
| BC1 解码 | DXT1，最常见的低质量压缩 | P0 |
| BC3 解码 | DXT5，带 Alpha 的压缩格式 | P1 |
| PNG 输出 | 解码结果保存为可视化图像 | P0 |

### 1.2 非目标 (Out of Scope)

- ASTC 解码（移动平台格式，复杂度高）
- BC6H 解码（HDR 格式，特殊用途）
- BC2/BC4/BC5 解码（后续版本）
- GPU 硬件解码

### 1.3 约束条件

- **零外部依赖**：不依赖 `texture2ddecoder` 等第三方库（除 PIL）
- **PIL 可用**：PIL 11.3.0 已安装，用于 PNG 输出
- **纯 Python**：优先纯 Python 实现，性能不足时再优化

## 2. 技术方案选择

### 2.1 方案对比

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| **纯 Python** | 零依赖，易维护 | BC7 性能可能慢 | ✅ 首选 |
| texture2ddecoder | 现成库 | 需安装，可能有兼容问题 | ❌ |
| 调用外部工具 | 性能好 | 需额外安装 texconv | ❌ |
| C 扩展 | 性能最好 | 开发复杂 | ❌ 后续优化 |

### 2.2 纯 Python BC 解码原理

**BC1 (DXT1)**:
- 4x4 块 = 8 字节
- 2 个 RGB565 颜色 + 16 个 2-bit 索引
- 生成 4 色调色板，索引选色

**BC7 (BPTC)**:
- 4x4 块 = 16 字节
- 8 种模式，每种有不同的颜色/Alpha 编码
- 最复杂，但有参考实现可用

## 3. 任务分解 (Task Checklist)

### Phase 1: 基础架构 (30 min)

- [ ] **Task 1.1**: 创建 `texture_decoder.py` 模块框架
  - 位置: `scripts/rdc_analyzer/decoders/texture_decoder.py`
  - 定义 `decode_texture()` 接口
  - 支持格式注册机制

- [ ] **Task 1.2**: 添加 PNG 输出工具
  - 使用 PIL 将 RGBA bytes 保存为 PNG
  - 支持 SRGB/线性颜色空间转换

### Phase 2: BC1 解码器 (45 min)

- [ ] **Task 2.1**: 实现 BC1 块解码
  - 输入: 8 bytes
  - 输出: 4x4 = 16 RGBA pixels
  - 处理 RGB565 颜色解包

- [ ] **Task 2.2**: 实现 BC1 纹理解码
  - 遍历所有块
  - 拼接为完整图像

- [ ] **Task 2.3**: 验证 BC1 解码
  - 用测试数据验证正确性
  - 输出 PNG 可在图像查看器打开

### Phase 3: BC3 解码器 (30 min)

- [ ] **Task 3.1**: 实现 BC3 块解码
  - BC3 = BC1 颜色 + 独立 Alpha 块
  - Alpha 块: 2 参考值 + 16 个 3-bit 索引

- [ ] **Task 3.2**: 验证 BC3 解码

### Phase 4: BC7 解码器 (90 min)

- [ ] **Task 4.1**: 实现 BC7 模式解析
  - 解析首位确定模式 (0-7)
  - 每种模式有不同的位布局

- [ ] **Task 4.2**: 实现 BC7 颜色端点解码
  - 根据模式提取颜色端点

- [ ] **Task 4.3**: 实现 BC7 索引解码
  - 每像素的索引位数因模式而异

- [ ] **Task 4.4**: 验证 BC7 解码
  - 使用真实 RDC 中的 BC7 纹理验证

### Phase 5: 集成与测试 (30 min)

- [ ] **Task 5.1**: 集成到 `extract_texture_from_zipxml.py`
  - 添加 `--decode` 参数
  - 自动检测格式并解码

- [ ] **Task 5.2**: 端到端测试
  - 从 `大远景.rdc` 提取 BC7 纹理
  - 解码为 PNG 并验证

- [ ] **Task 5.3**: 更新文档
  - 更新 Implementation Guide
  - 添加格式支持说明

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| BC7 性能太慢 | 4K 纹理超时 | 先实现正确性，后续用 Numba/Cython 优化 |
| 某些 BC7 模式有 bug | 部分纹理解码错误 | 逐模式验证，参考规范实现 |
| SRGB 转换不正确 | 颜色偏差 | 查阅 Vulkan 规范，正确实现 gamma 校正 |
