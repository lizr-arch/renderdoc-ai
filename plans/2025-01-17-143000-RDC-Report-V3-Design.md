## 一、设计背景

### 1.1 当前问题

| 问题 | 严重程度 | 用户反馈 |
|------|----------|----------|
| 纹理无法预览 | 🔴 高 | "点击纹理会出现找不到的情况" |
| 资源只显示名称 | 🔴 高 | "int resource 根本不知道数值多少" |
| Sampler 被误分类 | 🟡 中 | 已修复 |
| 缺少视觉层次 | 🟡 中 | "资源显示很不好" |

### 1.2 调研结论

参考了以下工具的 UI 设计：
- **Grafana**: 信息密度高、侧边栏概览
- **NVIDIA Nsight**: 专业图形分析布局
- **RenderDoc 原生 UI**: Pipeline State 树形结构
- **Chrome DevTools**: Performance 时间线
- **shadcn/ui**: 现代深色主题

```
┌─────────────────────────────────────────────────────────────────┐
│  🔍 RDC Analyzer         [📄 capture.rdc]     [🌙 Dark Mode]    │
├──────────────┬──────────────────────────────────────────────────┤
```

| 设计点 | 原因 |
|--------|------|

| **Tab 切换主内容** | 沿用当前方案（已验证有效），优化样式 |

## 四、资源数值显示

### 4.1 问题

当前报告只显示资源名称（如 `MyIntParam`），用户无法知道实际值。

### 4.2 解决方案：分层展示

```
┌─ Shader Resources ──────────────────────────────────────────────┐
│  ├─ 📦 Constant Buffers (3)                                     │
│  │   ├─ cbuffer ViewParams [b0]                    📊 [Expand]  │
│  │   │   ┌─────────────────────────────────────────────────┐   │
│  │   │   │ float4x4 ViewMatrix = [matrix values...]        │   │
│  │   │   │ float3 CameraPos = (0.0, 2.5, -5.0)             │   │
│  │   │   │ float  Time      = 12.456                       │   │
│  │   │   │ int    FrameIdx  = 42                           │   │
│  │   │   └─────────────────────────────────────────────────┘   │
│  │                                                              │
│  ├─ 🖼️ Textures (5)                          [→ View All]       │
│  │   ├─ Texture2D Albedo [t0]     ──────────────  [👁️ thumb]   │
│  │                                                              │
│  └─ 🎚️ Samplers (2)                                             │
│      ├─ SamplerState LinearWrap [s0]                            │
│          Filter: MIN_MAG_MIP_LINEAR | AddressU: WRAP            │
└─────────────────────────────────────────────────────────────────┘
```

| 设计点 | 原因 |
|--------|------|
| **树形折叠结构** | 借鉴 RenderDoc Pipeline State 面板，减少视觉噪音 |
| **Constant Buffer 内联展开** | **解决核心痛点**：直接显示 `Time = 12.456` |
| **Sampler 属性摘要** | Filter 和 Address Mode 是最关键属性 |

## 五、视觉设计规范

### 5.1 配色方案（Dark Mode）

```css
:root {
  --bg-primary:    #1a1a2e;   /* 深蓝黑背景 */
  --bg-secondary:  #16213e;   /* 次级背景 */
  --bg-card:       #0f3460;   /* 卡片背景 */
  --accent:        #e94560;   /* 强调色（RenderDoc 红） */
  --text-primary:  #eaeaea;   /* 主文字 */
  --text-secondary:#a0a0a0;   /* 次要文字 */
  --border:        #2a2a4a;   /* 边框 */
  --success:       #4ade80;   /* 成功 */
  --warning:       #fbbf24;   /* 警告 */
  --error:         #f87171;   /* 错误 */
}
```

| 设计点 | 原因 |
|--------|------|
| **深色主题为默认** | 图形调试器标准，深色减少眩光，纹理颜色更准确 |
| **RenderDoc 红作为强调色** | 品牌一致性 |

### 5.2 字体规范

| 元素 | 字体 | 大小 |
|------|------|------|
| 代码 | `JetBrains Mono`, `Consolas` | 13px |
| 标题 | `Inter`, `Segoe UI` | 18px |
| 正文 | `Inter`, `Segoe UI` | 14px |
| 数据 | `JetBrains Mono` | 12px |

## 八、设计决策总结

| # | 设计决策 | 原因 |
|---|----------|------|
| 1 | 深色主题为默认 | 图形调试行业标准，纹理颜色还原准确 |
| 2 | 左侧固定概览 | 借鉴 Grafana，减少 Tab 切换 |
| 3 | 网格+表格双视图 | 视觉浏览 vs 数据筛选，满足不同需求 |
| 4 | Lightbox 纹理预览 | 用户直觉，点击放大是通用交互 |
| 5 | RGBA 通道切换 | RenderDoc 核心功能，调试 Normal/Mask 必需 |
| 6 | 树形资源折叠 | 资源量大时减少噪音 |
| 7 | Constant Buffer 值内联 | **解决核心痛点** |
| 8 | 全局搜索 ⌘+K | 现代应用标准 |
| 9 | 代码高亮 | 可读性基本要求 |
| 10 | 关联资源内嵌 | 减少跳转 |
